# Aula: primeiros passos no ExpxV

Vídeo: `aula-primeiros-passos-expxv.mp4` (1m46, narração com a voz Luciana do macOS, legendas em `aula.srt`).
Gravada numa instalação limpa (`--user-data-dir` temporário) com um projeto de demonstração descartável.

## Roteiro

### Tela Hoje (instalação limpa)

Olá! Nesta aula você vai dar os primeiros passos no ExpxV. Esta é a tela Hoje, de uma instalação limpa, ainda sem nenhum projeto. Ela mostra o caminho em três passos: abrir um projeto, instalar o método Expx e criar a primeira Missão.

### Abrir projeto

Vamos ao primeiro passo. Clique em Abrir projeto. Você pode abrir uma pasta que já existe, clonar um repositório ou começar um projeto novo. Aqui vamos abrir uma pasta.

### Projeto aberto

Pronto. O projeto aparece no topo da janela, junto com a branch atual. E o primeiro passo ficou marcado como concluído.

### Terminais

Agora, os Terminais. Aqui ficam terminais de verdade, onde você roda as suas CLIs de inteligência artificial, como o Claude Code ou o Codex. Você também pode usar o terminal normalmente, como este exemplo.

### Método Expx

O segundo passo é o método Expx. Nesta tela você descreve o que quer construir ou corrigir, e o ExpxV digita o comando certo no terminal para você. Repare no aviso: a suíte só é instalada quando você clica em instalar. Nunca acontece sozinho.

### Missões

O terceiro passo é criar uma Missão. Uma Missão reúne uma CLI e um objetivo dentro do projeto, e o quadro mostra todas elas por estágio.

### Paleta de comandos (⌘K)

Por fim, um atalho que vale ouro. Aperte comando K para abrir a paleta, e digite o nome de qualquer tela ou ação para ir direto até ela.

### Encerramento

É isso. Abra um projeto, use os terminais, peça ao método e acompanhe as Missões. Bons estudos!
